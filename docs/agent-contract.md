# ORCA Shared Specialist Agent Contract

All four specialist agents implement the identical callable interface defined in `backend/app/agents/base.py`.

## Python Interface Definition

```python
class BaseAgent(ABC):
    agent_id: str
    name: str
    description: str

    @abstractmethod
    async def run(self, task: InvestigationTask) -> AgentResult:
        """Execute agent analysis for the given investigation task."""
        pass
```

## Standard Pydantic Models

### Input: `InvestigationTask`
- `investigation_id` (str): UUID of the parent investigation.
- `workspace` (WorkspaceType): One of `fisherman`, `marine_monitoring`, `protected_areas`, `coastal_authority`, `disaster_management`.
- `prompt` (str): User question / objective.
- `latitude` (Optional[float]): Geographic coordinate.
- `longitude` (Optional[float]): Geographic coordinate.
- `target_time` (Optional[datetime]): Timestamp for observation or forecast inquiry.
- `context` (dict): Shared contextual data or previous agent outputs passed by Orchestrator.

### Output: `AgentResult`
- `agent_id` (str): Identifier of the agent (`ocean_research`, `marine_hazard`, `coastal_risk`, `evidence_verification`).
- `status` (AgentStatus): `completed`, `partial`, `unavailable`, or `failed`.
- `findings` (List[Finding]): List of concrete claims, values, units, and supporting evidence references.
- `evidence` (List[EvidenceRecord]): Supporting evidence entities collected or generated by this agent.
- `limitations` (List[str]): Data gaps, temporal bounds, or assumptions explicitly declared.
- `errors` (List[str]): Operational errors or timeouts encountered.

### Finding Schema
- `claim` (str): Concise assertion or measurement statement.
- `value` (Optional[float | str]): Measured or calculated value.
- `unit` (Optional[str]): Standard scientific unit.
- `category` (FindingCategory): `observation`, `forecast`, `historical_record`, `deterministic_calculation`, `ai_interpretation`.
- `evidence_ids` (List[str]): Identifiers of evidence records validating this claim.
- `uncertainty` (Optional[str]): Methodological uncertainty bounds.
- `verification_status` (VerificationStatus): Default `unverified` until checked by Verification Agent.
