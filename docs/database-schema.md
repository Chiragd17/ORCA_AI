# ORCA Shared Database Schema & Conventions

The ORCA platform uses PostgreSQL with SQLAlchemy 2.x and Alembic migrations.

## 1. Global Conventions
- **Timestamps**: All timestamps stored with timezone in UTC (`DateTime(timezone=True)`).
- **Coordinates**: WGS84 standard: `latitude` (-90 to 90) and `longitude` (-180 to 180).
- **Units**: Stored explicitly alongside numerical values (e.g., `sst_celsius`, `wave_height_meters`, `wind_speed_knots`).
- **Idempotency**: All ingestion scripts enforce unique constraints on natural keys (e.g. `(source, external_id, timestamp)`).

## 2. Core Entities

1. **`data_sources`**: Catalog of data providers (Open-Meteo, NOAA IBTrACS, GDACS, WorldPop, OSM).
2. **`marine_observations`**: Temporal and spatial marine observations (SST, salinity, wave height, chlorophyll).
3. **`hazard_events`**: Tropical cyclones, storm surges, disaster alerts.
4. **`hazard_tracks`**: Track points, intensity, pressure, wind radii, coordinates, and observation times.
5. **`coastal_features`**: Coastal settlements, infrastructure, emergency facilities, ports, protected areas.
6. **`investigations`**: Multi-agent investigation sessions, workspace tag, user prompt, location, final answer, status.
7. **`investigation_events`**: Granular execution events emitted during orchestration (`event_type`, `agent_id`, `details`, `timestamp`).
8. **`evidence_records`**: Provenance records with stable evidence IDs, source URLs, timestamps, coordinates, values, and quality flags.
9. **`investigation_findings`**: Specific claims/findings generated by agents, linked to evidence IDs and verification states.
